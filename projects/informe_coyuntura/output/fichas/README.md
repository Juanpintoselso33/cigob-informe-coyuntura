# Fichas vigentes y entregas conservadas

Los cuatro `fichas-*.md` corresponden al snapshot local de la web y se
regeneran con el pipeline. Su vigencia se comprueba con las pruebas de fichas.

Los archivos Word conservan entregas anteriores al equipo. No son un espejo
automático del snapshot actual. El documento de Espíritu de época es
histórico: ese cinturón fue retirado y no pertenece al monitor vigente.

Para preparar una nueva entrega, seguir el [procedimiento](../../scripts/fichas/README.md)
y verificar valores, colores, pesos y diseño antes de enviarla. No modificar
una entrega histórica para hacerla pasar por actual.
