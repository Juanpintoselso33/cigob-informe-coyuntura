# Task 1 Report: Cortes y color en `parametrica.py`

## What Was Implemented

Implemented the 4-color traffic light ("semáforo") layer as a reading-only feature that maps tension values (0-10) to visual colors (verde, amarillo, naranja, rojo). The implementation includes:

1. **`CORTES_SEMAFORO` constant**: Tuple defining the tension thresholds for each color:
   - verde: tension ≤ 4.0
   - amarillo: tension ≤ 6.0  
   - naranja: tension ≤ 8.0
   - rojo: tension ≤ INF

2. **`color_de_tension(tension: float) -> str`**: Returns the color for a given tension value (0-10, unrounded)

3. **`color_de_puntaje(puntaje: float) -> str`**: Converts a 0-100 score (ITCM/ITCG/ITCP) to its equivalent tension and returns the color

4. **`color_de_indice_base100(indice: float) -> str`**: Converts a base-100 index (ITVC) using its own tension formula and returns the color

**Key design decisions respected:**
- Color calculation ALWAYS uses unrounded tension (critical for correct borders)
- Border convention: low exclusive / high inclusive (e.g., 4.0 is verde, 4.01 is amarillo)
- For base-100 ITVC: unified yardstick with verde = tension ≤ 4 (índice ≥ 105)
